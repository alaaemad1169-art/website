# AgriCore - The Core of Agricultural Careers in Egypt & Arab Region

🌾 **AgriCore** is an integrated recruitment, matchmaking, and career platform tailored specifically for the agribusiness and food science industries across Egypt and the Arab world.

---

## 🚀 Features

* **Multi-Criteria Candidate Matching Engine**: 5-pillar matching algorithm weighing specialization, skills, years of experience, governorate/location, and education level.
* **Supabase Production Auth & RLS**: Secure authentication with PostgreSQL Row Level Security (RLS) policies protecting candidate CVs and employer records.
* **Bilingual Arabic/English Design System**: Tailored for regional agricultural specialists and agribusinesses.
* **Role-Based Portals**:
  * 🌾 **Seeker Dashboard**: Job applications, resume snapshots, matching scores.
  * 🏢 **Company Portal**: Vacancy publishing, talent discovery, applicant tracking.
  * 🎓 **AgriCore Academy**: Sector courses (HACCP, ISO 22000, GlobalGAP, Smart Irrigation).
  * 📊 **Market Insights**: Agritech reports and industry trends.

---

## 🛠️ Technology Stack

* **Frontend**: HTML5, Vanilla CSS3 (Custom Design System), Modern JavaScript (ES Modules)
* **Backend / Database**: Supabase (PostgreSQL 15+, Auth, Storage, Triggers)
* **Deployment**: Vercel ready (Zero-configuration static deployment)

---

## 📦 Deployment to Vercel

This repository is structured for instant zero-configuration deployment to Vercel:

1. Push this repository to GitHub.
2. Go to [vercel.com](https://vercel.com) and click **Add New Project**.
3. Import this repository.
4. Click **Deploy**.
